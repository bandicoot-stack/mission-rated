# Agent Handoff

## Objective
What outcome is being pursued?

## Current status
Use one: `not_started`, `in_progress`, `blocked`, `review`, `done`, `ongoing`.

## Completed
List only completed work that the next agent should not repeat.

## Next action
State the single best next action.

## Settled decisions
Record decisions already made and their source when relevant.

## Unresolved questions / blockers
List only decisions that still need resolution.

## Evidence
Reference repo paths, PRs/issues, public sources, tests, or safe native-system descriptions. Do not paste secrets/private correspondence.

## External side effects already performed
Examples: email sent, PR merged, production deployed, automation created. Verify native state before assuming this remains current.

## Approval gates still pending
State explicitly. Never infer approval from preparation work.

## Recovery notes
Anything an incoming model needs to avoid duplicate work, unsafe assumptions, or lost context.
