# Skill: Public Research

## Use when
Researching businesses, deals, events, competitors, sources, or public facts.

## Procedure
1. Resolve the exact entity and geography.
2. Prefer first-party/official sources for factual claims.
3. Capture source URL, claim, freshness/date, and confidence.
4. Separate confirmed facts from inference.
5. Cross-check high-impact or conflicting facts.
6. Return a compact evidence package to the Operator.

## Output contract
- entity
- confirmed facts
- military offer/eligibility if any
- source + freshness for each time-sensitive claim
- conflicts/unknowns
- recommended next action

## Guardrails
Never fabricate an offer, veteran-owned status, partnership, rating, verification, hours, location, or redemption method.
