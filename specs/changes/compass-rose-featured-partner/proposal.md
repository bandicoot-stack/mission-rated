# Change Proposal: Compass Rose featured partner

## Problem / opportunity

Compass Rose Realty Co. directly confirmed a servicemember discount with Mission Rated, but the production Featured Partners experience currently only surfaces Yorktown Tools.

## Desired outcome

Compass Rose Realty Co. appears in the homepage Featured Partners view with the exact directly confirmed offer and redemption instructions, without changing ratings, rankings, verification policy, or unrelated layout.

## In scope

- Add Compass Rose Realty Co. to the canonical featured-partner registry.
- Display its directly confirmed $100 inspection offer in the homepage Featured Partners view.
- Preserve Yorktown Tools as an existing featured partner.
- Keep outbound clicks distinct from redemption or documented savings.

## Out of scope

- Inventing a Mission Rated business profile, rating, ownership claim, logo, expiration date, or savings event.
- Changing organic ranking or Mission Score.
- Redesigning the homepage.

## User stories

- As a servicemember, I want to see Compass Rose Realty Co.'s confirmed offer so I can use the benefit.

## Acceptance criteria

- [ ] Compass Rose Realty Co. is visible in Featured Partners.
- [ ] Offer copy states $100 off home inspections for buyers or pre-listing home inspections for sellers.
- [ ] Eligibility is servicemembers.
- [ ] Redemption instruction says to tell Compass Rose Realty Co. the offer was found on Mission Rated.
- [ ] The offer is labeled directly confirmed.
- [ ] Yorktown Tools remains visible with its current treatment.
- [ ] No click is represented as a confirmed redemption or documented savings.
- [ ] Mobile and desktop remain usable.

## Constitutional checks

- [x] Trust / sponsorship / ratings implications reviewed.

- [x] Mobile and accessibility behavior defined where relevant.
- [x] SEO / AI discovery implications reviewed where relevant.
- [x] Privacy, consent, and data-retention implications reviewed where relevant.
- [x] Security implications reviewed where relevant.
- [x] Required QA and production verification identified.
